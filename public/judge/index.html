Nonprofit volunteer management

More time for service. Less time managing it.

CivicFlow connects volunteer opportunities, shift staffing, check-ins, verified hours and reporting. Its offline-first desktop application uses an explainable scheduling optimizer called AutoRoster.

Evidence against the judging criteria

How to evaluate the program.

The interface is a working educational demonstration. Each claim below has a corresponding screen or source file for independent inspection. Desktop-only features are identified separately.

UX / Navigation

Follow both user journeys

Start from mission control as a coordinator, then switch to the volunteer view to inspect discoverability, scheduled shifts and service records. Keyboard focus, help and accessible field labels are implemented in the app.

Intelligent Feature

Explain each staffing choice

AutoRoster exposes eligibility, availability and skill reasoning. A coordinator reviews the proposed assignments before applying any plan; the optimizer is deterministic, not an opaque chatbot.

Output / Code Quality

Inspect reports and the engine

Explore configurable CSV/PDF report fields and filters, then inspect the TypeScript user interface and modular Rust optimizer in the source. Preview accounts and sample records are not a real authentication service.

National scoring also considers clear language selection, comments, validation and presentation delivery. This demonstration is evidence for judging, not a claim of a perfect score. Official event guidance.
